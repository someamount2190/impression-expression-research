This curated copy replaces named model, system, and project labels in code, records, and documentation with neutral placeholders or generic identifiers. Selected source filenames have also been renamed. User-specific local paths are redacted. Reported methods, measurements, and outcome descriptions are retained where practical.

The anonymized snapshot is not byte-for-byte identical to the original records. Experiment-level hashes in copied receipts identify original artifacts and may not match the anonymized copies. `research/SOURCE_MANIFEST.json` hashes the files in this anonymized snapshot. Exact model identity and upstream provenance are intentionally withheld. Running the copied training/evaluation code requires setting the documented `[BASE_MODEL_*]` configuration values and restoring omitted authorized artifacts.
